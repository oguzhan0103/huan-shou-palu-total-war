本项目是《幻兽帕鲁》1.0 “势力划分／势力版图 Mod”的安全实施基线。第一版坚持：不制作新地图、新 NPC、新服饰；不覆盖原地图；优先引用本体的瞭望塔、区域遮罩、地图 UI、势力文本与传送对象；只增加维持稳定契约所需的最薄逻辑层。
