# 【请先看】《幻兽帕鲁全面战争》v1.0.5 下载与卸载说明

发布日期：2026-08-24
GitHub：<https://github.com/oguzhan0103/huan-shou-palu-total-war>
兼容目标：Palworld Steam Build `24575825`

## 普通玩家下载哪个文件

要安装机制运行时，下载：

```text
PalFactionTerritory0-v1.0.5-build24575825-runtime-source.zip
```

已有安装、只想快速卸载，下载：

```text
PalworldTotalWar-v1.0.5-Quick-Uninstall.zip
```

两个 ZIP 同页都有 `.sha256.json`，可用于确认下载文件没有损坏。

## 一分钟安装

1. 退出 Palworld。
2. 自行安装与当前游戏匹配的 Palworld 专用 UE4SS。
3. 解压 `runtime-source.zip`。
4. 把压缩包根目录下的内容复制到：

```text
Palworld/Pal/Binaries/Win64/ue4ss/
```

5. 通过 Steam 启动游戏。

注意：这是 source-only 开源机制基座。公开包不含 Pocketpair 游戏资产，也不含本地
验收使用的三个 Cooked PAK，因此只安装公开 Lua 包不能还原所有地图、UI 和自定义商店
画面。

## 一分钟卸载

安装包根目录已经带有：

```text
快速卸载_幻兽帕鲁全面战争.cmd
```

双击后，工具会：

1. 自动定位 Palworld；
2. 列出本项目的精确目录和三个专属 PAK；
3. 等待玩家输入大写 `UNINSTALL`；
4. 自动备份 Mod 自有 State；
5. 删除本项目 Core、误装的 QA Harness 和本项目三个 PAK；
6. 再次检查目标确实已移除。

它不会删除 Palworld 存档、Steam 云存档、UE4SS、其他 Mod、原版 PAK 或可选
`PalMultiOtomo0`。State 备份默认位于：

```text
文档/PalFactionTerritory-UninstallBackups/
```
