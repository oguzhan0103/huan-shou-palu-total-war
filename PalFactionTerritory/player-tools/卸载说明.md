# 《幻兽帕鲁全面战争》快速卸载说明

普通玩家双击：

```text
快速卸载_幻兽帕鲁全面战争.cmd
```

工具会自动寻找 Palworld，先显示将要处理的完整路径。确认路径正确后，输入大写
`UNINSTALL` 才会真正删除。

## 默认会删除什么

- `ue4ss/Mods/PalFactionTerritory0/`
- `ue4ss/Mods/PalFactionTerritoryQAHarness0/`（如果误装过测试 Harness）
- `Pal/Content/Paks/LogicMods/PalFactionTerritory0.pak`
- `Pal/Content/Paks/~mods/PalFactionTerritory_FactionEconomyShops_P.pak`
- `Pal/Content/Paks/~mods/PalFactionTerritory_RayneMerchant_P.pak`

这些都是本项目专属的精确文件名。目标不存在时会跳过，可重复执行。

## 默认不会删除什么

- Palworld 世界存档和 Steam 云存档；
- UE4SS 本体、`dwmapi.dll`、UE4SS 日志；
- 其他作者的 Mod 和 Palworld 原版 PAK；
- 可选扩展 `PalMultiOtomo0`；
- 卸载时自动生成的 Mod State 备份。

如果检测到 `PalFactionTerritory0/State`，工具会先备份到：

```text
文档/PalFactionTerritory-UninstallBackups/日期-时间/State/
```

这份备份只包含本 Mod 自有的好感、任务、唯一帕鲁和操作台侧车状态，不是
Palworld 世界存档。确认不需要后可由玩家自行删除。

## 常见情况

1. 提示游戏仍在运行：完全退出 Palworld 和 Unreal Editor 后再执行。
2. 无法自动找到游戏：打开 PowerShell，显式指定游戏根目录：

```powershell
powershell -ExecutionPolicy Bypass -File .\Quick-Uninstall-PalFactionTerritory.ps1 `
  -GameRoot "E:\SteamLibrary\steamapps\common\Palworld"
```

3. 只想预览，不删除：

```powershell
powershell -ExecutionPolicy Bypass -File .\Quick-Uninstall-PalFactionTerritory.ps1 `
  -PreviewOnly
```

4. 开发者需要无交互卸载：

```powershell
powershell -ExecutionPolicy Bypass -File .\Quick-Uninstall-PalFactionTerritory.ps1 `
  -GameRoot "E:\SteamLibrary\steamapps\common\Palworld" -Yes
```

5. 同时删除官方可选多帕鲁扩展：追加 `-RemoveOfficialAddons`。默认不删除，避免
   用户把独立扩展误当作 Core 的必然组成部分。

工具拒绝递归删除符号链接或目录联接，也不会删除宽泛目录。若安装路径异常，工具会
停止并要求人工检查，而不是扩大删除范围。
