# 风险与验证计划

## 风险清单

| 等级 | 风险 | 当前控制措施 | 解除条件 |
|---|---|---|---|
| 阻塞 | 缺当前 build `.usmap` / SDK | 不解析未知属性、不猜蓝图签名 | 用兼容 1.0.1 的 UE4SS/PalSchema 或 Mod Kit 生成并留档 |
| 阻塞 | 24 塔与 20 遮罩精确映射未知 | 只登记塔 ID；除 1 号候选外遮罩为空 | DataTable/蓝图默认值或 LiveView 实证 |
| 高 | 地图 UI 更新后 Hook 失效 | 不替换 WBP；接入前做函数/属性存在性检查 | 当前版本实机日志与 UI 回归 |
| 高 | 只禁地图传送仍可场景交互绕过 | 设计为双入口 + 权威侧复核 | 地图、场景、客户端伪请求三类测试均通过 |
| 高 | 多人关系状态不同步 | 势力关系与传送判定由主机/服务器权威 | 单机、监听服务器、Windows 专服测试 |
| 高 | 犯罪 UI 触发 Wanted 副作用 | 第一版推迟，不调用犯罪状态 API | 独立展示测试证明 Crime/Wanted 不变化 |
| 中 | 红绿辨识与色盲 | 信息窗同时显示关系文本；颜色不是唯一信号 | 可访问性检查与实机截图 |
| 中 | 与其他地图 Mod 冲突 | 运行时附加子控件，不覆写原资产 | 与常见地图 Mod 组合测试 |
| 中 | 保存/卸载污染 | 自有 versioned 状态；不改原塔解锁数据 | 复制存档的安装、保存、卸载、再加载测试 |
| 中 | 叙事 OOC | 仅使用本体原文与明确证据；未知所有者保持空 | 完成任务 Flow/Team/地点证据联结 |

## 验证阶梯

### A. 离线核心（已完成）

- 契约包含且只包含 24 个唯一瞭望塔 ID。
- 原始地图模式不产生势力图层。
- 敌对／友好／中立分别解析为红／绿／蓝。
- 未解锁区不绘制势力层并保留原迷雾。
- 关系 revision 更新会即时改变颜色与传送结果。
- 地图信息使用本体塔名、势力名、塔主名，并随关系更新文字。
- 敌对领地公共传送被阻止。
- 入境事件只在跨区进入敌对领地时产生一次。

### B. 运行时框架冒烟

1. 在独立开发副本安装与 build 匹配的运行时框架。
2. 启动到标题画面，确认没有新崩溃。
3. 保存 UE4SS/PalSchema/Mod 日志与精确版本。
4. 用 `-NoMods` 验证可恢复到纯净状态。

### C. 数据与 UI 垂直切片

只启用 `WatchTower_1`：

1. 解锁前原迷雾不变。
2. 解锁后原地图外观不变。
3. 切到势力版图后仅该区域出现关系色。
4. 地图信息显示本体势力名、佐伊和当前关系。
5. 切回原始地图后 Overlay 完全消失。
6. 修改关系时不重开地图即可刷新。

### D. 传送与绕过

- 地图点击敌对区传送点：阻止。
- 在敌对区传送雕像交互：阻止。
- 友好／中立：保持本体可用规则。
- 剧情传送、死亡重生、地牢出口：不受影响。
- 客户端发起伪请求：主机／服务器拒绝。

### E. 存档与卸载

必须使用复制存档：

- 新档、旧档各一次。
- 保存退出、重启、再加载。
- 关系状态与本体塔解锁各自保持。
- 禁用 Mod 后原地图和原传送恢复。
- 删除 Mod 自有状态后仍能加载世界。

### F. 多人

- 单机通过后，再测试监听服务器。
- 最后测试官方当前仅支持的 Windows Dedicated Server Mod 路径。
- 只在双方都具备必要客户端 UI 时宣称多人兼容。
