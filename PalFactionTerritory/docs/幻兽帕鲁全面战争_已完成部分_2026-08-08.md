# 幻兽帕鲁全面战争 公开发布清单（截至 2026-08-08）

## 已完成（可公开基座）

### 1) 人类势力与帕鲁袭击核心
- 小型聚落入侵机制完成：基于 `PalNPCManager.SpawnNPCForServer` 原生刷 4/4 史莱姆袭击者（含候选、解析、AI 激活、居民优先仇恨、活性销毁）。
- 采用 `fail-closed` 策略：刷怪失败不改写原生普通野生帕鲁。
- 原生生命周期销毁机制完成（含计数与日志断言）。
- 攻击结果与信物系统可通过离线验证链路回传给规则层（`record_raid_result` 已纳入契约与状态机）。

### 2) 商人商会与经济接口
- 商人商会七柜台部署与回收实机通过（7 个不同商店行、7 个势力资源映射）。
- 原生 ItemShop 交互与打开流程可用，二次打开、关闭与回收可持续。
- 商人轻后端桥接完成（商户注册、商铺绑定、交互球初始化、交易事件路径）。
- 商业数据结构与平衡基础完成：商品组/抽选组、供应/需求信号、库存与单价模型落库。

### 3) 帕鲁和解（离线）底座
- `contracts/pal_reconciliation.v1.json` 与 `pwft.pal_reconciliation` 规则引擎完成：
  - 信物配额
  - 有限论道机会与永久锁死
  - 任务完成门闩
  - 可逆/不可逆确认、技术故障返还
  - 好感度原子结算、红转蓝门槛、世界结局联动
- `PWFT_PAL_RECONCILIATION_API_V1`、`PWFT_FACTION_STATUS_API_V1` 与外部内容包接口完成。
- `pal_discourse_runtime` 完成离线文本树执行运行时（基于本地化 key，不包含内嵌剧情文本）。
- F5 势力状态面板接入上述底座数据。

### 4) 工程与验收
- 最新源码/安装/资源审计通过。
- 关键 lua 离线验证通过（`39` 文件，`33` 项测试）。
- 2026-08-08 两大实机验收通过：`40_帕鲁攻城与商人商会最终实机验收_2026-08-08.md`。

## 尚未完成（不应标注为“正式对外可玩”）

### A) 帕鲁“和解式聊天/论道”玩家可见交互（核心体验缺口）
- 原生帕鲁代表生成、附近交互体、不可逆确认窗口与对话 UI 还未接通。
- `nativeDialoguePresenterEnabled` 当前仍关闭；当前仅为离线运行时与规则层底座。

### B) 部分经济与交易体验
- 该轮实机验收未完成“真实购买收益导致的好感度/补差结算”闭环。
- 商队好感逻辑在基座中有框架，但未完全启用为玩家可见主体验收条目。

### C) 上线发布动作
- 项目本体还未完成 GitHub 仓库创建与公开 release（仍待远端创建与首发推送）。
