## 3. 公共传送

关键对象：

- `/Game/Pal/Blueprint/UI/UserInterface/Map/WBP_Map_Body::CanFastTravel`
- `/Game/Pal/Blueprint/MapObject/Object/LevelObject/BP_LevelObject_TowerFastTravelPoint`
- `/Game/Pal/Blueprint/MapObject/BuildObject/BP_BuildObject_FastTravelPoint`

`BP_LevelObject_TowerFastTravelPoint` 暴露或引用：

- `CheckUnuseFastTravel`
- `bEnableFastTravel`
- `bEnableFastTravelOnlyBaseCamp`
- `IsUnlocked`
- 世界设置变化回调

因此只改地图按钮不足以防止绕过。实现时同时接入地图层与对象交互层，并由服务器／主机权威逻辑复核目标领地关系。

## 4. 犯罪提示 UI 评估

候选：

- `WBP_Crime_Found`
- `WBP_Crime_FoundList`
- `WBP_Crime_Scene`
- 外层 `WBP_Crime`

发现的耦合：

- `WBP_Crime_Found` 接收 `CrimeIds`，调用 `SetCrimesFound`、`SetCrimeName`，读取 `DT_UI_Common_Text`，并播放 `AKE_Crime_Found`。
- `WBP_Crime_FoundList` 根据 Crime ID 组装 DataTable RowHandle，不是任意文本 Toast。
- `WBP_Crime_Scene` 固定引用 `CRIME_CRIMING` 和犯罪暗角材质。
- 外层 `WBP_Crime` 同时管理 Wanted Rank、犯罪列表、警戒计时和 Crime Scene。

结论：**第一版不复用该 UI。** 在当前证据下，“只换文字、其余原封不动”仍可能要求伪造 Crime ID 或操纵犯罪 HUD 状态，语义与技术耦合都过高。接入点保留为 `PalHUDService` 与上述 WBP；只有 LiveView/SDK 证实可以单独创建展示 Widget、直接覆盖文本且不写入犯罪状态时再恢复。

## 5. 本体文本复用

- 势力名来自本体建筑描述、任务、帮助或 NPC 文本键。
- 塔名来自 `DT_MapRespawnPointInfoText`。
- 地图原名使用 `WORLDMAP_NAME_MainMap_TextData`。
- 快速传送错误优先沿用本体错误提示样式；敌对原因最多新增一条短文本。
- 控制者／塔主名称引用本体人物文本键或明确署名日记，不自由改写人设。
