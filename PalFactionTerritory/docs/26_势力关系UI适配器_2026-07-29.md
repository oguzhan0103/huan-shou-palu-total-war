# 势力关系 UI 适配器（2026-07-29）

## 结论

玩家可见势力关系 UI 的开发底座已完成并通过离线验证，当前状态为：

```text
dedicated-faction-panel-ready-live-acceptance-pending
```

这表示代码、UMG 资产、显式开关和离线测试已经就绪，但尚未启动《幻兽帕鲁》进行分辨率、输入、字体和实际显示验收。

## 玩家入口

- 默认按键：`F5`
- 第一次按下：在玩家控制器和 Pawn 都存在时创建并显示面板。
- 再次按下：隐藏面板。
- 标题界面不会自动创建面板。
- 势力状态变化时，仅在面板可见的情况下更新原生文本控件。

## 显示内容

- 7 个人类势力和 5 个帕鲁势力。
- 红/蓝/绿关系状态。
- 好感度、是否可加入、成员/核心成员/领队/领主进度。
- 固定市场商业额度和敌对外交修复进度。
- 领队起的护卫资格及原生提供器状态。
- 帕鲁和解解锁状态、缺失的人类领主数。
- 结局三状态、缺失的帕鲁友好势力数。

不包含任务文本、剧情对白或剧情内容。

## 原生资产

PMK 项目：

```text
E:\mod\PalworldModdingKit\Pal.uproject
```

Widget：

```text
E:\mod\PalworldModdingKit\Content\Mods\PalFactionTerritory0\UI\FactionStatus\WBP_PFT_FactionStatus.uasset
```

本次从空白 `UUserWidget` 建立：

- 根节点 `CanvasPanel_1`。
- 摘要容器 `BTN_FactionSummary`。
- 文本控件 `TXT_FactionSummary`。
- 摘要容器位置为 `X=660, Y=55`，尺寸为 `575×610`。
- 文本控件在按钮槽内横向、纵向铺满。
- 资产在 PMK 中编译成功并保存。

专用资产中没有地图图像、地图切换按钮、复选框或旧地图 Widget 依赖。现行地图势力展示继续由原生世界地图上的整岛划分材质负责，F5 关系面板只展示关系和机制状态。代码不调用 `StaticConstructObject`，不读取私有 `WidgetTree`，不动态制造 `UImage`/`UTextBlock`。

旧 `WBP_PFT_TerritoryMap` 仅作为历史回退资产保留。Primary Asset Label 会递归 Cook Mod 目录，因此它仍可能出现在 PAK 文件清单中；Presenter 不引用它，专用 Widget 的依赖扫描也不包含它。
