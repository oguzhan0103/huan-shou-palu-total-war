# 世界平衡独立开关与全图扫描隔离

日期：2026-07-30  
状态：**开发、全量离线回归、部署与安装审计 PASS；三个能力默认关闭，待分阶段实机验收**

## 1. 修复的问题

旧 `WorldBalance` 用一个总开关同时启动：

- 全世界非玩家单位 80 级；
- 五个帕鲁势力岛的狂暴/捕食者、双倍生命、双倍伤害和不可捕捉；
- 读档后两轮 `FindAllOf` 全图 Actor 补偿扫描。

隔离测试曾证明单独统一 80 级可以运行，但把属性修改和全图枚举合在同一个启动
阶段后出现不稳定与闪退。旧安全模式只能把整个模块一起关闭，无法按风险逐项恢复。

## 2. 当前实现

`worldBalance` 现在拆成三个独立开关：

```lua
levelOverride.enabled = false
palFactionRage.enabled = false
loadedActorReconcile.enabled = false
```

- `levelOverride` 只在两个原生角色初始化事件中调用瞬时
  `SetOverrideLevel(80)`。
- `palFactionRage` 只处理出生/初始化事件中的合格野生帕鲁，仍排除玩家帕鲁、
  据点工作帕鲁和训练师所属帕鲁。
- `loadedActorReconcile` 单独控制两轮 `FindAllOf` 补偿枚举；默认关闭时不会注册
  地图加载补偿，也不会运行全图枚举。
- `demoNativeRaidSafeMode` 允许未来只开启 `levelOverride`；如果误开启狂暴或
  全图补偿，则整个世界平衡模块失败关闭，不干扰小型聚落兽潮验收。
- 三个开关当前全部为 `false`，所以本轮部署不会在下次进档时修改任何单位。
