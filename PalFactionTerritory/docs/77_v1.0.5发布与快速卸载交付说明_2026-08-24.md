# 《幻兽帕鲁全面战争》v1.0.5 发布与快速卸载交付说明

日期：2026-08-24
兼容目标：Palworld Steam Build 24575825
发布边界：source-only 机制基座

## 1. 本版内容

v1.0.5 汇入 2026-08-22 至 2026-08-24 完成的源码、自动测试、公开实机证据和
部署合同，详细清单见 `docs/76_周六以来完成工作汇总_2026-08-22至2026-08-24.md`。

核心增量包括 B0/B1/B2/B4/B5/B6、A8/A9 和五只基础岛唯一帕鲁 B7 全链路。
剧情与详细设定继续作为内容包密钥，不进入 Core 默认正文。

## 2. 快速卸载工具

新增 `player-tools/`：

- `Quick-Uninstall-PalFactionTerritory.ps1`：权威卸载实现；
- `Quick-Uninstall-PalFactionTerritory.cmd`：ASCII 双击入口；
- `快速卸载_幻兽帕鲁全面战争.cmd`：中文双击入口；
- `卸载说明.md`：玩家和开发者参数说明。

卸载器只允许操作以下精确目标：

```text
ue4ss/Mods/PalFactionTerritory0/
ue4ss/Mods/PalFactionTerritoryQAHarness0/
Pal/Content/Paks/LogicMods/PalFactionTerritory0.pak
Pal/Content/Paks/~mods/PalFactionTerritory_FactionEconomyShops_P.pak
Pal/Content/Paks/~mods/PalFactionTerritory_RayneMerchant_P.pak
```

默认保留 `PalMultiOtomo0`；只有显式追加 `-RemoveOfficialAddons` 才会移除。递归删除前
会验证绝对路径、父目录和 reparse-point 边界。State 默认备份到用户文档目录，
SaveGames、UE4SS、共享 `dwmapi.dll`、其他 Mod 和原版 PAK 不在删除范围。

## 3. 自动验收

`tools/test_quick_uninstall.ps1` 在随机临时假游戏目录覆盖：

1. Preview 不产生任何写入；
2. Core、QA Harness 和三个专属 PAK 精确删除；
3. State 先备份并生成 SHA-256 清单；
4. UE4SS、其他 Mod、原版 PAK和可选扩展保持不变；
5. 第二次执行幂等通过；
6. 显式参数可以单独移除官方可选扩展；
7. 测试结束后只清理自身随机临时目录。

该测试已并入 `scripts/verify-mod0.ps1`，发布包构建前也会再次运行。
