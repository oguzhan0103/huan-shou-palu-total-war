# 整岛双层势力地图基线（2026-07-22）

## 已确认显示规则

- 势力范围的最小几何单位改为一座完整岛屿或一个完整群岛，不再把瞭望塔迷雾范围当成政治边界。
- 海洋始终透明；当前图层中没有归属的岛屿也完全透明。
- 按 `N` 的顺序固定为：原地图 → 人类势力 → 帕鲁势力 → 原地图。
- 敌对势力为红色 `#D34A4A`，友方势力为蓝色 `#4D86D9`，玩家自己的势力为绿色 `#4FAF68`。
- 玩家进入区域后的地名染色、危险提示和公共传送限制只读取人类势力图层；帕鲁势力图层仅负责地图展示，默认关系为敌对。

## 技术边界

地图仍然复用本体的 `Image_MapBody`、拖动、缩放、图标和传送交互。Mod 只把一个海洋透明、海岸线对齐的政治色层绑定到已有 `Image_MapMask`；不写探索迷雾、不改存档、不替换本体地图贴图。

关系颜色和显隐使用两套独立材质参数：`Color_01..20` 只负责红、蓝、绿，`Visibility_01..20` 只负责当前图层是否拥有该岛。这样无主岛屿不会依赖颜色 Alpha 的 UI 混合行为。

整岛轮廓从本体世界地图贴图的陆地像素提取。旧 `T_MapMask_*` 只作为“这座岛属于哪个已确认区域”的粗选择器，不再成为玩家可见的边界。
