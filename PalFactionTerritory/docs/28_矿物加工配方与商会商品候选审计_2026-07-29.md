# 矿物加工配方与商会商品候选审计

日期：2026-07-29  
状态：**九种初始加工品的正式配方、物品 ID 和原生基础价格已完成离线审计；价格倍率、库存和采购额度待定；未启用商店**

## 一、审计目的

本轮承接商人商会的供需规则：

- 势力不以出售原矿为主要表现；
- 势力拥有某种资源，就供应对应加工成品；
- 资源越多，成品库存越多、售价越低；
- 势力缺少的物资进入采购清单；
- 玩家成功出售采购物资后，获得对应势力商业好感度。

本轮只确认正式配方、内部物品 ID 和原生基础价格，不猜最终价格与库存。

## 四、已纠正的旧假设

### 4.1 六棱晶锭不是 `ManganeseIngot`

正式文本与配方确认：

```text
StainlessSteel = 六棱晶锭
配方：Chromium ×1 + RainbowCrystal ×1
```

而：

```text
ManganeseIngot = 珊瑚锭
配方：ManganeseOre ×2 + Coal ×5
```

所以旧的未启用天坠军商品原型中，`ManganeseIngot` 不能继续被当作六棱晶锭。新经济契约只允许使用 `StainlessSteel` 表示六棱晶锭。

### 4.2 聚合物不能按原油分布直接计算

当前正式配方是：

```text
PalOil ×2 + Sulfur ×1 → Polymer ×1
```

岛屿原油 `CrudeOil` 对应的是塑钢等原油加工链，不是聚合物的直接原料。

### 4.3 古代熔岩块暂不做大宗加工品

`Lava_Ancient` 在审计表中直接进入四种装备配方，没有对应的大宗加工材料。当前可以把它保留为火山特殊采购/限量装备输入，但不伪造新的通用熔岩锭。

### 4.4 烈阳金属锭不纳入当前七岛基线

```text
SkyislandIngot = 烈阳金属锭
配方：SkyIslandOre ×2 + Quartz ×2
```

当前七岛矿物调查没有纳入烈阳矿归属，因此不把烈阳金属锭塞给天坠军或其他现有势力；等对应新区域正式划入势力版图后再处理。

## 五、对七势力商品方向的影响

1. 金属锭可以由东南、森林、沙漠、雪山、火山共同供货，价格按有效金属产能区分。
2. 精炼金属锭必须同时看金属矿与石炭，沙漠优势最大；雪山虽有金属矿，但因石炭稀少，不能成为精炼金属锭低价主产区。
3. 电路板的势力供给强弱按本地纯水晶判断；聚合物由已有商人渠道补充，只进入成本底线，不再阻塞地区供给信号。
4. 塑钢同时依赖原油与金属矿。天坠原油最多却没有基础金属矿，因此其塑钢成本应受进口金属影响。
5. 六棱晶锭的两个核心矿物都只在天坠之地出现，可作为天坠军最明确的高阶出口商品。
6. 火药的势力供给强弱按本地硫磺判断；木炭由已有商人渠道补充，只进入成本底线。
