# 商人商会与七岛矿物产出调查

日期：2026-07-29  
状态：**矿物地点事实表、供需方向、九种初始加工品配方与原生基础价格已完成离线审计；首版价格、库存和采购额度已完成离线计算，待用户确认与实机校准；未启用运行时商品配置**

## 一、当前商人设计修正

1. `FTPoint90` 泰拉瑞亚密域小岛暂定为独立的**商人商会**。
2. 商人商会不属于任何人类势力或帕鲁势力，负责连接各地势力、组织跨岛交易。
3. 雷恩盗猎集团的全图鉴帕鲁商人是特殊兜底：
   - 后续世界狂暴化后，玩家可能无法按正常方式捕捉帕鲁；
   - 因此保留一个可购买帕鲁的特殊渠道；
   - 该特例不能外推为“每个势力都应拥有直属商人”。
4. 之前七势力商人合同中的人物、颜色、商品行和生成计划暂时只保留为未启用的技术原型。
5. 在用户确认商会柜台、代理关系和商品范围前，不制作自定义商品 PAK，不启用原生商人生成。

### 1.1 2026-07-29 用户确认的经济规则

1. 势力是商品的**供应方和需求方**，商人商会只是连接各势力与玩家的中立交易渠道。
2. 势力拥有某种自然资源时，不以出售原矿为主要表现，而是出售由该资源支撑的**加工成品**。
   - 例如：势力拥有大量金属矿石，商会中的该势力供货窗口出售金属锭。
3. 同一种成品可以由多个势力出售，不强行设为某个势力独占。
4. 同一种资源越多：
   - 对应成品库存越多；
   - 对应成品售价越低。
5. 反过来，势力缺少某类资源或产能时，会通过商会采购对应物资。
   - 玩家把该势力明确需求的物资卖给对应窗口，交易成功后获得该势力好感度。
   - 不在采购清单内的普通出售不增加势力好感度。
6. 玩家购买势力的供货商品，以及向势力出售其需求商品，均可作为商业好感度来源；两者继续受商业好感度额度限制，商业不能单独把势力关系刷到领主。
7. 商业路线允许形成“在产区低价采购、到缺货势力出售”的跨岛贸易玩法。库存、采购额度、交易去重和好感度上限负责控制无限套利。

经济链条固定为：

```text
地区资源储量
  → 势力有效生产能力
  → 加工成品库存
  → 商会出售价格

地区资源缺口
  → 势力采购需求
  → 商会采购清单
  → 玩家成功出售
  → 该势力商业好感度
```

对应离线数据契约：

```text
PalFactionTerritory/contracts/faction_economy.v1.json
```

该契约与旧 `faction_commerce.v1.json` 分工不同：

- `faction_economy.v1.json` 管资源、产能、成品供给、库存、售价和采购需求；
- `faction_commerce.v1.json` 继续只管原生交易结算、交易去重和商业好感度换算；
- `faction_progression.v1.json` 继续管理商业好感度额度、敌对修复、身份和结局门槛。

## 二、调查范围

本轮只调查矿物，不把以下内容混入矿物结论：

- 帕鲁掉落；
- 农作物、木材、药材和食物；
- 势力可能制造的武器、弹药、零件或加工品；
- 地下城宝箱和任务奖励；
- 尚未划入当前七岛势力版图的天阳乡、世界树等新区域。

矿物名称采用本地 1.0 简体中文文本：

- `CopperOre`：金属矿石；
- `Coal`：石炭；
- `Sulfur`：硫磺；
- `Quartz`：纯水晶；
- `CrudeOil`：原油；
- `Chromium`：铬铁矿；
- `RainbowCrystal`：六棱晶矿；
- `Lava_Ancient`：古代熔岩块。

## 五、从点位可以直接得出的结论

### 5.1 强地域特产

- **沙漠岛：石炭。**
  - 普通石炭点和石炭矿脉均显著高于其他当前势力岛。
- **雪山岛：纯水晶。**
  - 纯水晶点位接近当前七岛总量的绝对主体。
- **火山岛：硫磺。**
  - 硫磺和硫磺矿脉高度集中，另有少量古代熔岩块。
- **天坠之地：铬铁矿、六棱晶矿。**
  - 当前七岛内只有天坠之地拥有这两类高阶矿点。

### 5.2 跨区域资源

- **金属矿石**广泛存在于东南、森林、沙漠、雪山和火山，不适合简单宣称为某个势力独占。
- **原油**分布于沙漠、雪山、樱岛、火山和天坠之地；天坠之地点位最多，但原油本质上仍是跨区域资源。
- **石炭**除沙漠外，森林和火山也有稳定产出。
- **硫磺**以火山为主，但森林、樱岛和东南群岛也有少量点位。
- **纯水晶**以雪山为主，东南、森林和沙漠仍存在少量点位。

### 5.3 当前不应强行分配的地点

- 东南群岛矿物以普通金属矿石为主，没有明显独占矿。
- 中央森林矿物种类较全，但没有压倒性的独占资源。
- 樱岛拥有石炭、硫磺和原油，但三者均不是该岛独占。

因此，不能为了凑齐“一个势力对应一种矿”而伪造地域特色。这三个地点是否通过加工、运输、折扣、采购需求或非矿物商品建立商业身份，应在下一轮由用户决定。

## 六、第一版供需方向

本表只确定方向，不等于最终商店商品表。九种初始加工品的本地 1.0 配方、物品 ID 和原生基础价格已经完成审计，详见：

```text
PalFactionTerritory/docs/28_矿物加工配方与商会商品候选审计_2026-07-29.md
```

| 资源链 | 主要供货势力与初始价格方向 | 主要采购势力 | 当前解释 |
|---|---|---|---|
| 金属矿石 → 金属锭 | 雪山、沙漠供给较强；东南、森林、火山稳定供给。最终价格按有效产能排序 | 樱岛、天坠之地 | 金属锭不是单一势力特产，应存在多个价位和库存 |
| 石炭 → 精炼金属/碳材料 | 沙漠最低价和最大库存候选；森林、火山为稳定供给；樱岛小库存候选 | 东南、雪山、天坠之地 | 沙漠石炭优势应直接反映在加工品价格 |
| 硫磺 → 火药/弹药/爆炸物 | 火山最低价和最大库存候选；森林、樱岛为小库存候选 | 沙漠、雪山、天坠之地；东南为较强需求 | 火山是硫磺主产区，但不强制垄断所有火药商品 |
| 纯水晶 → 电路板/电子零件 | 雪山最低价和最大库存候选；森林仅小库存候选 | 樱岛、火山、天坠之地；东南、沙漠为较强需求 | 雪山的纯水晶优势应转成稳定电子工业供给 |
| 原油 → 油加工材料/塑钢上游 | 天坠、沙漠、火山为主要供给；樱岛、雪山小库存候选 | 东南、森林 | 原油跨区域存在，按数量形成多个价格层 |
| 铬铁矿 + 六棱晶矿 → 天坠高阶制品 | 天坠之地独占关键原料供给，但成品仍可能受进口金属制约 | 其余六个人类势力 | 独占原料不等于无限低价成品，必须计算其他配方输入 |
| 古代熔岩块 → 对应加工品 | 火山独占候选 | 其余势力是否采购待配方确认 | 先确认正式配方和用途，再决定商品化 |

按当前金属矿点位，金属锭的最直观例子是：

```text
雪山 256 / 沙漠 244
  → 金属锭供给较多、价格较低

东南 171 / 火山 170 / 森林 169
  → 金属锭供给稳定、价格居中

樱岛 0 / 天坠之地 0
  → 不作为本地金属锭供货方，转为采购金属锭
```

上面的数字仍是地图点位，不是实际矿石产量。矿脉权重和单点刷新产量必须在用户授权集中实机测试后校准，当前不伪造精确产量。
