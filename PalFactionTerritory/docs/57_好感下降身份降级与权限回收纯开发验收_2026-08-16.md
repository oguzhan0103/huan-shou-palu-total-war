# 好感下降、身份降级与权限回收纯开发验收

日期：2026-08-16

状态：**合同、源码、生成物、自动测试完成；未部署到游戏目录，未启动 Steam、Palworld、UE4SS 或 Unreal Editor，未进入存档，未形成新增实机或用户接受证据。**

## 1. 冻结语义

- 负向好感只适用于 7 个人类势力；5 个帕鲁势力仍只能通过既有有限信物与论道机制从敌对恢复为友好。
- 合法变更必须包含受信权威、枚举原因码、非零 delta、唯一操作 ID 和稳定内容签名。同 ID 同内容只重放；同 ID 不同内容拒绝。
- 合同边界为 `-1200..1200`，单次负向事件最多扣 300。该数值仍属待实机平衡档案，不得写成用户最终确认值。
- 已加入势力在 0 或负数时不被自动踢出。0 点为 Member / Player；负数为 Member / Hostile。
- 商业数值恢复和既有外交恢复都遵守每窗口总计最多 20 点；固定商会商业停火继续保留，不因敌对关系撤销恢复入口。
- 客户端文本、控制台任意参数和 Ollama 输出没有负向写权限；`pwft.progress grant` 已失败关闭。

## 2. 实现范围

- `contracts/faction_progression.v1.json` 升至 `1.1.0`，新增变更权威、原因、上下界、成员保留、自动降级和权限回收政策。
- `faction_progression.lua` 新增统一 `apply_reputation_delta`、签名账本、冲突拒绝、升降级结果、最后一次变更摘要和旧载荷迁移。
- `faction_api.lua` 的任务、防御、商业接口保持原签名并改走统一 delta 核心；新增受信负向入口。
- `faction_guard.lua` 新增单势力及全局资格重算；降到 Leader 以下时幂等召回现役护卫。
- `quest_runtime.lua` 支持任务模板 `1.1` 的人类势力、最低身份、最低好感门槛；失去资格时暂停目标与状态转换，保留进度，恢复后继续。
- `runtime.lua` 在同一状态变更回调中依次重算关系、护卫、任务、sidecar、Companion、雷恩商人、通用商人、F5 与 NPC 态度；延迟身份恢复也执行同一权限协调。
- sidecar 文件名和 envelope 保持兼容；载荷 `1.0` 可从主文件或备份加载后迁移为 `1.1`，未知 A0–A9 扩展节点原样保留，并在下一次正式保存写回。
