# B5 任务与防守闭环开发与实机验收

日期：2026-08-23

游戏版本：v1.0.3.101283 / Steam Build 24575825

结论：`PASS`

## 1. 本次关闭的蓝图缺口

B5 同时关闭两个原先只有纯机制源码、没有游戏内组合证据的工作包：

1. 无剧情任务模板能够监听权威玩法事件并自动完成；
2. 玩家实际参与且赢得人类据点防守后，对映射人类势力只结算一次防守好感。

新增 `task_defense_closure.lua` 作为组合路由。它只接受防守结果桥输出的权威结果，把好感结算与任务目标事件绑定到同一个事件 ID；内容模块仅提供结构化任务、本地化键和据点映射，不写剧情正文。

## 2. 内容模块与默认安全边界

验收模块 `pwft.foundation.b5-acceptance` 包含：

- 1 个小型聚落防守任务模板；
- 1 条 `defense/completed` 目标规则；
- 雷恩盗猎集团、小型聚落和东南群岛的结构化映射；
- 仅用于说明机制的本地化键。

模块声明 `defaultEnabled=false`、`storyContentIncluded=false`。正式 `config.lua` 的 `contentModules.modules` 保持空列表，因此验收内容不会随正式基座自动加载。Mod 的持久化仍只写自己的 State 侧车，`PalworldSaveMutation=false`。

## 3. 自动测试

专项测试覆盖：

- 一次参与且胜利：任务完成、好感 `+50`；
- 重放同一事件：任务不重复转换、好感 `+0`；
- 玩家缺席或失败：好感 `+0`、任务不完成；
- 缺少领土映射：失败关闭；
- 内容包默认关闭、无剧情、无原生存档写入。

全量校验覆盖 84 个 Lua 源文件和 73 个 Lua 测试文件。以上负向分支属于自动测试证据，不冒充实机。

## 4. Build 24575825 实机正向链路

实际操作链路：

1. 在地图点击 `FTPoint24`，触发原生 ClickEvent 与原生快速传送确认，到达小型聚落；
2. 启动 5 秒 QA 倒计时，在据点附近生成 4 名原生 1 级攻击者；
3. 4/4 攻击者完成战斗就绪，玩家在场并位于仇恨范围内；
4. 玩家所属帕鲁击杀 4/4 攻击者，头领击杀归因有效；
5. 权威结果确认全员死亡、玩家方胜利；
6. 同一事件为雷恩盗猎集团结算防守好感 `+50`，示例任务推进 1 次并完成。

持久化读回确认：雷恩好感为 50、`sourceTotals.defense=50`、好感操作记录 1 次、任务状态 `completed`、任务序号 1、目标事件记录 1 次。

因此本次结论是：**B5 的通用机制、自动负向边界和 Build 24575825 正向实机组合闭环均已完成。** 它不代表正式剧情已创作，也不代表玩家已经进行主观验收。

公开证据：`evidence/live-tests/build24575825-20260823-b5-task-defense/`。完整 UE4SS 日志、玩家存档、Mod State 和本机路径只保留在私有测试输出，不进入仓库。

## 6. 内容作者接入方法

内容作者复制该模块时只需替换：

1. `manifest.lua`：模块 ID、版本、依赖；
2. `quest_template.lua`：任务 ID、阶段、目标规则和好感目标势力；
3. `localization_keys.lua`：显示文本键；
4. `content_module.lua`：据点、势力、领土映射与自动启用策略。

不要在 Core 中硬编码剧情正文，也不要绕过 `pwft.defense.v1` 权威门直接发放防守好感。
