# 唯一帕鲁 P2 生产注册与赎金交付组合验收

日期：2026-08-22

结论：**机制基座的 P2 生产交付接口已经完成并部署。受信内容包可以把经当前 Build 核验的世界效果 target binding、库存 1 的原生 ItemShop 赎金商品和已实机证明的 Pal 交付适配器接成一条严格事务。自动组合测试已证明一次服务器购买成功只产生一次逻辑归属转移、一次实体创建、一次捕获和一次相同 individual identity 仓库回读；重复支付回执不会二次结算。基座不携带剧情，也不猜写最终赎金、初始归属或正式地图目标，所以正式内容绑定和商品数仍为 0。**

## 1. 新增生产能力

- 新增 `unique_pal_native_delivery_production.lua`，把 Build 24575825 已验收的容量预检、服务器创建、服务器捕获、稳定 individual identity 和仓库精确回读能力封装成内容包生产注册器。
- 生产注册器只批准五项用户已确认映射：
  - `pwft.unique.pinkcat -> PinkCat`
  - `pwft.unique.anubis -> Anubis`
  - `pwft.unique.weasel_dragon -> WeaselDragon`
  - `pwft.unique.black_metal_dragon -> BlackMetalDragon`
  - `pwft.unique.ronin -> Ronin`
- 新地图／空涡龙项没有 species 和最终映射，生产配置、合同和测试均明确保持关闭。
- 正式适配器与 QA 适配器分离：生产等级为 80，QA 若临时启用仍使用自己的等级 1 配置；不会因为开放生产能力改变旧 QA 语义。
- 内容模块上下文新增 `uniquePalNativeDeliveryProduction`。内容包必须先注册 Provider 和精确 world-effect target binding，再提交同 generation、同 provider、同 route 的 approved species 子集。
- 地图卸载会清空 generation-scoped Provider、target、赎金商品和 Pal 交付绑定；地图重新载入后，`ContentModuleLoader` 只重新调用受信 `activate(context)`，不会重复注册数据包，也不会复用上一代 UObject。

## 2. 正式赎金商品合同

`contracts/unique_pal_delivery_production.v1.json` 把“正式商品”定义为内容密钥，而不是基座内置剧情物品：

- 原生通道必须是 ItemShop；库存 1、购买数量 1、币种 Gold；
- 静态商品价格必须等于内容包 `uniquePalCampaign.ransomPrice`；
- 商人势力必须等于当前唯一帕鲁持有势力；
- Provider 必须绑定确切 `nativeOfferId / shopId / productId / merchantFactionId / unitPrice / ransomPaymentKey`；
- 只有服务器购买成功回执可确认支付；取消、余额不足、错误商品、错误价格、错误势力和旧 generation 全部失败关闭；
- 赎金交易商业好感固定为 0；支付成功与 Pal 已交付是两个独立权威阶段。

基座的 `baseRegisteredBindingCount` 和 `baseRegisteredProductCount` 都固定为 0。这样发布的仍是“底座”，玩家提供价格、剧情与地图资产绑定后才组成完整内容包。

## 3. 组合事务测试

`mod0/tests/unique_pal_ransom_native_delivery_e2e_spec.lua` 使用真实 Core 状态机和桥接模块，串联：

`ItemShop 请求 -> RecieveBuyResult_ToClient 成功 -> 零商业好感 -> Core 赎金确认 -> 唯一归属转玩家 -> pal-delivery -> 容量预检 -> 创建一个 approved species -> 捕获一次 -> 同一 individual 仓库回读 -> Core delivery 完成`

通过断言：

- 一笔库存 1 的服务器成功购买只结算一次；
- `ransomPrice = 99,999,999` 的测试内容价格在商品、Core 和支付回执三处完全一致；该数值仅是测试夹具，不是正式剧情价格；
- 商业好感调用次数为 0；
- 逻辑归属只从 PIDF 测试持有者转给本地玩家一次；
- `create / capture / storage readback` 均为 1 次且 individual key 完全一致；
- 重放相同原生交易为幂等，不再次付款、不再次生成 Pal；
- 错误 species、旧 generation 和暂定 Feybreak 映射拒绝注册。
