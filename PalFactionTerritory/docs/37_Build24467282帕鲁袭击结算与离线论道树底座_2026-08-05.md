## 2. 规范化袭击结果适配器

新增 `pwft/pal_raid_result_adapter.lua`，导出：

```lua
_G.PWFT_PAL_RAID_RESULT_ADAPTER_V1
```

确定规则：

1. 事件必须来自 `PalInvaderIncident` 权威来源并带唯一事件 ID、群组 GUID 和最大波次。
2. 当前原生 Grade 5 Meadow 组没有显式唯一头领，因此 MOD 把“最终波次第一个观察到的生成成员”确定为本次唯一头领。
3. 只承认两类击杀：本地玩家 UID 明确匹配；或 `IsPlayersOtomo` 与 `Trainer` 都明确指向本地玩家的出战帕鲁。
4. 远程玩家、队伍、公会或任何归因不明情况当前不算有效参与。
5. 只有原生结束回调、玩家方胜利、全部波次清空和头领击杀归属同时成立，才把结果交给有限信物服务。
6. 清理计时器永远不能结算；同事件重复结束幂等；同一演员或死亡出现冲突证据时，整次事件失效关闭。

当前 `nativeRaidResultBindingEnabled = false`。适配器已经可供原生绑定调用，但不会自行猜测或注册未经实机确认的回调。

## 3. 帕鲁代表与离线论道树

新增 `pwft/pal_discourse_runtime.lua`，导出：

```lua
_G.PWFT_PAL_DISCOURSE_API_V1
```

内容包可以注册：

- 帕鲁势力、信物总配额、单次最大好感度；
- 该势力的代表 ID、姓名本地化键和交互提示本地化键；
- 按信物城邦精确匹配或 `*` 兜底的离线分支树；
- 每个节点的说话方、文本键、选项文本键和下一节点；
- 确定性终点 `completed` 或 `player_abort`，以及内容作者指定但受上限约束的好感度。

基座会拒绝 `text`、`label`、`displayName` 等内联文本字段，只允许本地化键；同时拒绝环、无终点路径、不可达节点、未知城邦、重复代表和超过 64 节点的树。因此基础 MOD 提供结构，不代替粉丝写剧情。

会话规则：

- 代表、信物、已完成文本任务和“全人类势力领主”门槛全部通过后，才生成不可逆确认提案；
- 确认前拒绝或关闭，不预留也不消耗信物；
- 确认后由服务预留信物，正常终点或玩家主动退出都会消耗；
- 渲染器、本地化提供器或其他技术故障走独立退款接口；
- 所有分支和好感度结算由确定性规则引擎控制，Agent 不能直接修改状态。

当前 `nativeDialoguePresenterEnabled = false`，尚无原生帕鲁代表生成、附近交互碰撞体或玩家可见窗口。
