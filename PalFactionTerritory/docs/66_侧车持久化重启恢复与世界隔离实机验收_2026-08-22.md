- `payload.uniquePalBossProviderBus.worldGeneration`：12 → 13

## 4. 损坏主文件与备份恢复

在游戏完全关闭后，先备份 12 个 State 文件并记录 SHA-256，然后把当前 profile 的主 JSON 替换为不可解析的 36 字节故障夹具，同时保留有效 `.bak`。

再次进入同一世界后，日志明确给出：

```text
PROGRESSION_IDENTITY_READY ... sidecarWrites=true sidecarReason=active:backup
```

恢复结果：

- 有效 `.bak` 的 revision 2 被载入；
- 新主文件有效，revision 仍为 2；
- 损坏主文件被旋转到 `.bak`；
- `FACTION_PROGRESSION_RECOVERY_BLOCKED` 计数为 0；
- 与恢复源相比只增加上述两个 generation fence，其他耐久状态一致。
