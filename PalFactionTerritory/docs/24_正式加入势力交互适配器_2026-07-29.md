# 正式加入势力交互适配器

记录日期：2026-07-29  
状态：**统一内容适配器与离线回归完成；原生玩家界面待 UI 阶段接入**

## 已完成

- 七个人类势力各有稳定的注册入口：`pwft.join.source.<faction>`。
- 只有注册且启用的入口可以发起加入，帕鲁势力不能注册。
- 加入前返回当前资格、预计身份，以及会新增的外交敌对关系。
- 必须由玩家明确确认后才调用正式加入接口；拒绝不修改状态。
- 确认时再次检查关系和好感度，过期邀请不能绕过新出现的敌对阻断。
- 请求 ID 与确认 ID 防重复、防跨入口复用。
- 继续允许玩家加入多个人类势力，不降低任何好感度。
- 不包含任务、剧情、对白或势力文案。
- 运行时公共接口：`_G.PWFT_JOIN_API_V1`。

## 离线验证
