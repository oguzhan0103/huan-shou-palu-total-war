# 《幻兽帕鲁全面战争》未完成项收敛计划

更新日期：2026-08-11

目标版本：开源机制基座 `v1.0.2`

## 1. 发布边界

本轮继续交付“基座”，不在 Core 中写死剧情、任务正文、角色台词、信物名称或详细世界设定。机制、状态机、公共 API、内容包接口、失败回滚、离线测试和实机验收工具属于基座；剧情与详细设定由内容作者通过内容包提供。

状态口径固定为四类：

1. **已实机通过**：当前目标 Build 中已有同轮日志与画面证据。
2. **离线完成**：源码、契约和自动测试通过，但尚未在当前 Build 中完成玩家可见验收。
3. **待实机验收**：技术路线和测试入口已经存在，只差集中进游戏确认。
4. **未实现**：仍缺源码、Cooked 资产或必要的内容输入。

离线测试通过不得写成实机通过。发布包继续排除 Pocketpair 游戏资产、Cooked PAK、存档、日志、Steam 身份、绝对本机路径、API Key 和历史玄绒龙资源。

## 5. 集中实机验收门槛

游戏只能在用户明确发出实机测试指令后启动。集中测试按以下顺序执行，减少反复重启：

1. 只读确认 Build、Mod 挂载、正式配置和测试存档隔离状态。
2. F5 面板：打开、刷新、关闭、不同分辨率和输入焦点。
3. 商会正式落位：七柜台、七商品行、连续交互、购买、出售、额度和回收。
4. 人类代表：查看资格、确认加入、重复请求和敌对修复后加入。
5. 护卫：领队资格、生成、跟随、战斗、倒地、离开和回收。
6. 帕鲁代表：靠近门闩、离线论道、Agent 自由文本、玩家确认、主动退出、技术故障返还。
7. 帕鲁袭击结算：参与、胜利、头领归属、一次性信物和缺席分支。
8. 退出世界后核对临时实体全部回收、Mod 侧车可恢复、Palworld 原生存档未被直接改写。

## 6. 本轮已经开始的结果

本轮不是只列计划：批次 A 的 Core 对话控制器、商会结算重试、帕鲁代表原生呈现、人类加入代表原生路由，以及玩家人类护卫的原生生命周期均已经落地。人类加入路由因为 Core 不内置剧情 NPC，仍需内容包提供精确代表 Actor 后才能做实机验收；护卫的生成、实际跟随、召回和调度停止已经实机通过，战斗与死亡分支仍严格标记为离线通过。原生帕鲁袭击 4/4 Hook 已在当前 Build 注册，但强制启动被本体开放地面检查拒绝，因此完整信物发放保持待自然袭击验收。内容作者 SDK 与发布包内一键校验已经离线完成。
