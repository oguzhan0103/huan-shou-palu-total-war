# 内容作者 SDK 与发布包一键校验

日期：2026-08-11
目标版本：`v1.0.2`

## 结论

内容作者工具链已经达到 source-only 基座的离线完成标准：最小内容包同时覆盖 manifest、任务、战略世界、结局路线、本地化目录和帕鲁论道；仓库与发布 ZIP 都能用一条 PowerShell 命令完成原子校验。

示例只包含作者占位文本，不包含官方剧情、任务正文、信物名称或详细世界设定，也不携带 Pocketpair 资产。

## 仓库内校验

```powershell
powershell -ExecutionPolicy Bypass -File scripts/validate-content-pack.ps1 -PackPath examples/minimal-content-pack
```

## 发布 ZIP 内校验

```powershell
powershell -ExecutionPolicy Bypass -File AuthorSDK/validate-content-pack.ps1 -PackPath AuthorSDK/minimal-content-pack
```

校验器会自动识别两种目录布局，加载对应的 Core 脚本，然后在临时运行时中原子注册整包。任一领域失败时整包不提交。

## 已覆盖的拒绝条件

- 非法或冲突的 manifest、命名空间和 SemVer；
- 缺失依赖、显式冲突和加载顺序不确定；
- 未声明或跨包占用的本地化 key；
- 非法任务阶段、不可达分支或不一致的结构化结果；
- 非法论道树、循环、不可达节点或不终止路径；
- 任务、战略世界、结局、论道和本地化的内容包 ID/版本不一致；
- 模型或文本层试图直接修改确定性状态。
